# Bro

Restate your last message simply and coherently, like one human talking to another.

- Lead with the point. Use everyday words and short, complete sentences; remove jargon and unnecessary detail.
- Preserve the meaning, facts, citations, uncertainty, and caveats that affect the answer. Keep exact code, commands, identifiers, and quotations when changing them would change their meaning; explain technical terms in plain language when needed.
- Return only the restated message, without announcing the rewrite, adding new claims, or doing new work. This is a one-response rewrite, not a persistent setting.

Bro simplifies the last assistant message. For a broader edit of supplied prose to remove formulaic AI writing patterns, read and apply `skill://unslop` when that is what the user requests; do not automatically add that workflow to this rewrite.
